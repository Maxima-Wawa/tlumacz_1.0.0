# tlumacz_1.0.0
Inteligentny, lekki tłumacz ekranowy stworzony z myślą o graczach i użytkownikach aplikacji, które nie posiadają polskiej wersji językowej. Program działa w tle, nie obciąża komputera i nie zapisuje żadnych plików tymczasowych na dysku (cała analiza odbywa się bezpośrednio w pamięci RAM)
